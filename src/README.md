# Quellcode (Revierbuch)

`build_pwa.py` baut aus `revierbuch.html` und den JS-Modulen (`ansitz.js`, `hunt.js`, `plan.js`, `track.js`, `parcel.js`, `lotplan.js`, `seasons.js`) die ausgelieferten Dateien `index.html` und `sw.js` im Hauptverzeichnis.
Der Ordner `src/` wird von der App nicht benötigt.
